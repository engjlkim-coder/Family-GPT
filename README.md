# 가족 GPT PWA 3.2

휴대폰 중심 개인용 GPT PWA입니다.

## 3.2 주요 변경
- ChatGPT처럼 여러 대화를 별도로 저장
- `＋ 새 대화`로 새 대화 생성
- ☰ 대화 목록에서 기존 대화 다시 열기
- 대화 제목 자동 생성 및 직접 수정
- 대화 삭제
- 최대 30개 대화 저장, 대화당 최근 80개 메시지 보관
- JSON으로 전체 대화 백업/복원
- 3.1의 이미지 분석, 지식파일, 모델 선택, PWA 기능 유지
- Service Worker 캐시 버전 갱신

## 저장 방식
대화는 현재 사용 중인 휴대폰 브라우저의 localStorage에 저장됩니다. 서버 DB에 저장되는 방식이 아니므로 다른 기기와 자동 동기화되지는 않습니다. 다른 기기로 옮길 때는 `💾 백업`에서 JSON 저장 후 새 기기에서 JSON 불러오기를 사용합니다.

## Vercel 환경변수
- `OPENAI_API_KEY` : 필수
- `VECTOR_STORE_ID` : 지식파일 기능 사용 시 필요

GitHub 저장소를 Vercel 프로젝트에 연결하면 GitHub commit 후 자동으로 재배포됩니다. Vercel에 API 키를 직접 넣고 소스 코드에는 API 키를 넣지 마세요.
